# 作文：我们眼中的缤纷世界（水果）

## 正文

**题目：我爱橘子**

有人喜欢红彤彤的苹果，有人喜欢弯弯的香蕉，而我最喜欢的水果是橘子。它圆圆的，黄澄澄的，像一盏挂在枝头的小灯笼，看着就让人心里暖暖的。

远远望去，橘子像一个个小太阳，把秋天的果园照得亮堂堂的。走近一看，橘子的皮上布满了细细的小疙瘩，像穿了一件带花纹的外套。用手摸一摸，有一点粗糙；轻轻捏一捏，软软的，还带着弹性。凑近鼻子闻一闻，一股淡淡的清香钻进鼻子里，让人忍不住想马上剥开它。

剥开橘皮，一股更浓的甜香飘了出来。橘皮张开，像一朵黄色的小花；里面的橘瓣紧紧地抱在一起，像一群说悄悄话的好朋友。掰下一瓣，弯弯的，像一只金色的小船。放进嘴里轻轻一咬，酸酸甜甜的汁水一下子涌了出来，满嘴都是秋天的味道。

橘子不仅好吃，而且浑身是宝。它含有丰富的维生素，能提高我们的抵抗力；橘皮晒干后还能泡水、做药。听妈妈说，橘子还能清火呢。

我爱橘子，爱它可爱的样子，爱它酸甜的味道，更爱它给秋天带来的这份温暖。

## 写作思路（对照板书）

| 段落 | 板书要求 | 本文写法 |
|---|---|---|
| 一段 | 直接引入最爱的水果 + 总体特点 | 对比引入橘子，写圆、黄、像小灯笼 |
| 二段 | 外形：整体 → 局部 + 五感（视、触、嗅） | 远看像小太阳 → 近看小疙瘩 → 摸、捏 → 闻清香 |
| 三段 | 内部：视、触、嗅、味 + 感受 | 剥皮像小花 → 橘瓣像小船 → 酸甜汁水 |
| 四段 | 过渡句：不仅……而且…… | “橘子不仅好吃，而且浑身是宝” |
| 五段 | 价值 | 维生素、提高抵抗力、橘皮泡水、清火 |
| 六段 | 总结特点 + 表达喜爱 | 爱样子、味道和秋天的温暖 |

## 可借鉴的写法

- **比喻**：小灯笼、小太阳、黄色的小花、金色的小船
- **拟人**：橘瓣像一群说悄悄话的好朋友
- **五感顺序**：看 → 摸 → 闻 → 尝，让水果“活”起来
- **过渡句**：用“不仅……而且……”从“好吃”自然转到“有用”
