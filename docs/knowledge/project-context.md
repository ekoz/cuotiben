- **project-mode**: greenfield
- **业务域**: 个人学习 / 错题管理（语文、数学、英语）
- **架构风格**: 静态站点（VitePress 文档站）
- **技术栈**: Node.js v24.16.0 / VitePress / npm 11.17.0 / 无数据库
- **判定依据**:
  - greenfield: 当前仓库尚无稳定业务代码，技术方案按首版基线设计评审

> 评审口径：以基线架构合理性、可扩展性、运维可行性为主，不以历史兼容性为主。

## 项目目标

个人纠错本：长期累积语文、数学、英语的常见错题，便于按学科和学期回顾、订正与复习。

## 内容组织

学科（语文 / 数学 / 英语）→ 学期（如 2026-秋）→ 错题条目文件。

## 每道错题的固定结构

| 结构 | 说明 |
|------|------|
| 题目 | 原题内容（题干、选项、材料等） |
| 解题思路 | 关键步骤与易错点，保持精简 |
| 同类型练习 | 5 道同题型练习题 |
| 答案 | 5 道练习的答案，放在同一文件末尾 |

页面不显示学科、学期等元信息，录入日期以引用块放在页面末尾。作文条目按自身结构（正文 + 写作思路），不套用错题结构。
