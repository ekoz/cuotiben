# v1-site-skeleton

## Problem Statement

个人纠错本目前只有 HelixHarness 工程工件，没有任何可直接使用的内容载体：没有站点配置、没有内容目录、没有统一的错题结构。错题若以自由格式零散记录，字段不齐、无法按学科和学期回顾，也无法本地预览或构建成可浏览的站点。需要先建立一套可运行、可扩展的最小骨架，让后续每道错题都有确定的落位与格式。

## Solution

搭建 VitePress 静态站点骨架：内容根目录独立于 HelixHarness 工件，按「学科 → 学期 → 每题一文件」组织错题；提供固定四部分（题目、解题思路、5 道同类型练习、答案）的错题模板；页面不显示学科、学期等元信息，录入日期放在页脚；启用本地全文搜索与 KaTeX 公式渲染；侧边栏由配置动态扫描生成，并跳过没有内容的学期分组。骨架完成后，用户可本地预览、构建，并按模板持续录入错题。

## User Stories / Acceptance Criteria

- AC-01 — 作为仓库使用者，安装依赖后执行构建命令能成功生成站点产物，过程中无构建错误，以便确认站点可发布。
- AC-02 — 作为仓库使用者，启动本地预览后首页正常渲染，并展示语文、数学、英语三个学科入口，以便快速进入内容。
- AC-03 — 作为错题录入者，三个学科下都存在当前学期目录，可直接录入错题而不依赖示例条目，以便按学科和学期归档。
- AC-04 — 作为错题录入者，错题模板包含题目、解题思路、5 道同类型练习与答案四部分，已录入内容完整使用该结构，以便每条记录格式一致且可直接练习。
- AC-05 — 作为错题录入者，新增一个符合命名规范的错题文件后无需修改配置，侧边栏自动出现对应条目，以便零维护地扩展内容。
- AC-06 — 作为错题录入者，数学错题中的 LaTeX 公式能正确渲染，且站内搜索能检索到错题内容，以便复核公式与快速定位题目。

## Implementation Decisions

- D-01 — 站点内容根为仓库根级 `notes/`，VitePress `srcDir` 指向该目录；`docs/` 下的 HelixHarness 工件不进入站点。
- D-02 — 错题文件路径为 `notes/<学科>/<学期>/YYYY-MM-DD-<中文短标题>.md`，每题一文件。
- D-03 — 错题固定四部分：题目、解题思路、同类型练习 5 道、答案。
- D-04 — 同类型练习的答案放在同一错题文件末尾，便于复习时直接练习和核对。
- D-05 — 学科目录为中文：语文、数学、英语；学期目录为 `YYYY-秋` / `YYYY-春` 形式，当前学期为 `2026-秋`。
- D-06 — 侧边栏由 `config.mts` 内的 Node `fs` 扫描 `notes/` 生成，层级为「学科 → 学期 → 文件一级标题」；标题缺失时回退为文件名。
- D-07 — `notes/index.md` 为简单文档首页，列三个学科入口与使用说明，不使用 hero 布局与"最近错题"模块。
- D-08 — 启用 VitePress 本地全文搜索与 KaTeX 数学公式渲染。
- D-09 — 使用 npm 管理依赖，VitePress 取 1.x 当前稳定版；内容语言为中文。
- D-10 — 本次不配置部署。
- D-11 — 错题页面不显示学科、学期等元信息（由目录与侧边栏表达）；录入日期以引用块形式放在页面末尾；侧边栏跳过没有内容的学期分组。

## Testing Decisions

- 使用仓库最高层公共 seam：CLI 构建命令 `npm run docs:build` 成功退出且生成构建产物，覆盖 AC-01；本地预览命令 `npm run docs:dev` 可启动并由首页内容覆盖 AC-02。
- 以静态检查覆盖 AC-03 至 AC-05：目录存在、模板四部分齐全、命名符合 D-02、新增文件后构建产物侧边栏包含对应条目。
- KaTeX 与搜索能力通过构建产物与已录入内容验证，覆盖 AC-06。
- 无视觉验收要求。

## Out of Scope

- 后续真实错题内容的持续录入。
- GitHub Pages 或其他部署配置。
- 错题结构的自动校验脚本。
- Vitest 等单元测试框架。
- "最近错题"首页模块、标签、统计与间隔重复功能。

## Further Notes

- 学期目录结构以当前学期 `2026-秋` 起步；后续学期由录入者按同一规范新增，无需改配置。
- 作文条目按作文自身结构（正文 + 写作思路），不套用错题四部分模板。
