## 全局约束摘要

1. 所有站点内容使用中文（C-001）。
2. 新增错题必须落在「学科 → 学期」目录下，不混放（C-002）。
3. 错题条目必须包含题目、解题思路和 5 道同类型练习（附答案），缺项视为内容不完整（C-003、C-004）。
4. 保持静态站点形态；新增运行时能力须先走 Spec 评审，不在实现中直接引入未评审依赖（C-005）。
5. 未知事实保留 `TODO` 标注，不以猜测替代确认。
